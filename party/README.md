# PROJ_BH: 실시간 파티 던전 크롤러 (3단계: 종족 · 직업 · 파티 구성 · 해금)

Battleheart식 실시간 파티 조작에 DCSS를 단순화한 RPG 규칙(스킬, 저항, 상태이상, 마법 실패율)을 결합한 프로토타입입니다.
5층짜리 런: 층마다 방을 정리하고 계단으로 내려가며, 5층의 오우거 족장을 쓰러뜨리면 승리합니다.

## 실행

```bash
npm install
npm run dev        # http://localhost:5173
npm run sim -- 1 10   # 렌더링 없이 런 10번 자동 진행 (층별 사망 · 최저 체력 · 성장 결과)
npx vite-node scripts/corridor-test.ts   # 통로 차단 시나리오 점검 (MAP1)
```

## 구조

```
src/
  data/      데이터만으로 확장: abilities, statuses, units(파티/몬스터), items(장비·속성), encounters(층별 무리), maps
  sim/       게임 규칙 (DOM 의존 없음, 헤드리스 실행 가능)
    world.ts      한 층: 틱 루프, 시야, 전투 상태, 계단, 자동 탐험, 경험치, 플레이어 명령 API
    hero.ts       층을 넘어 이어지는 성장 데이터: 레벨, 자동 성장, 특성 선택
    items.ts      장비 생성, 장비·레벨업 보너스 합산
    reward.ts     층 보상 3택1, 장비 교체 시 수치 비교
    gen.ts        층 생성 (격자 위 방 경로 + ㄱ자 통로)
    behavior.ts   유닛 한 틱: 상태이상 → 시전 → 명령(우선) / AI 의도 실행
    ai.ts         유틸리티 점수 AI (전술 유형·대상 선호가 가중치만 바꿈)
    combat.ts     공통 피해/저항/상태이상 파이프라인, 평타
    abilities.ts  시전·실패율·범위 판정, AI용 기대 피해 계산
    stats.ts      모든 수치 공식
    movement.ts   경로 이동, 유닛/벽 충돌
    map.ts        타일맵, A*, 사선
  render/    3/4 탑다운 캔버스 렌더러, 카메라(좌표 변환은 여기만)
  input/     드래그 명령, 범위 선택, 스킬 대상 지정, 단축키, 터치
  ui/        DOM HUD (파티 카드, 스킬바, 적 정보, 로그), 쉬는 화면(rest.ts)
```

## DCSS 단순화 규칙

- 능력치 STR/DEX/INT, 스킬 0~10 (소수점까지 오른다)
- 저항 -1~+3 → 피해 150/100/50/33/20%, 독은 면역 여부만
- 상태이상: 확률 → 면역 태그 → 원소 저항 → 의지력(주문력 대비) 순 판정
- 마법 실패율 = (난이도×6 + 갑옷무게×1.5 − 계열스킬×2.5 − 주문시전 − INT×0.3) × 2%
- 시전 시간 0.8초 이상 마법은 피격 시 끊길 수 있음, 기절하면 무조건 끊김 (기술은 기절로만 끊김)

## 성장과 장비 (결정은 층 사이에 몰아서)

- **용병단 (다키스트 던전 식, `sim/roster.ts`, `ui/town.ts`)**: 거점에서 명부(최대 12명) 중 최대 4명으로 원정대를 꾸린다.
  선술집에서 무작위 후보 고용(120골드) 또는 원하는 종족 · 직업을 지정해 부르기(260골드). 종족 = 능력치 보정 · 고유 특성, 직업 = 장비 · 시작 기술 2개 · 특성 선택지
  (`data/races.ts`, `data/classes.ts`, `data/party.ts`). **영구 사망**: 쓰러진 용병은 층을 마칠 때 묘지로 간다.
  골드는 처치 · 층 돌파 · 보스로 벌고, 층을 마칠 때마다 귀환하면 챙기고 전멸하면 잃는다. 원정에 안 나간 용병은 스트레스가 준다.
  저장: 층 시작 시점 (`bh.company.v1`). 도중에 끄면 그 층 처음부터.
- **거점 시설 (탭)**: 치료소(스트레스 · 붕괴 치료, 1.2골드/점) · 대장간(보관함 장비 팔기 · 강화 +3까지 · 장착/벗기) ·
  훈련장(골드로 레벨 올리기 — 명부 최고 레벨 −1까지, 특성 되돌리기 · 고르기). 원정에서 끼지 않은 장비와 교체로 벗은 장비는 들고 와서 보관함으로 (전멸하면 잃는다).
- **해금** (`data/unlocks.ts`, `sim/meta.ts`): 런에서 한 일(누적 처치, 도달 층)로 새 종족 · 직업이 열린다. 강해지는 게 아니라 선택지가 늘어난다.
  브라우저 저장소에 기록 (`bh.meta.v1`).
- **레벨 성장은 자동**: 체력 · 위력(내부 스킬 수치: 직업 스킬 · 든 무기 +0.9, 그 밖의 기본기 +0.5)이 저절로 오른다. 스킬 수치는 화면에 나오지 않는다.
- **특성 (배틀하트 식, `data/talents.ts`)**: Lv 3 · 5 · 7 · 8 에 직업별 셋 중 하나. 단계 성격이 정해져 있다 —
  ① 기본 기술 변형(`mod`) ② 새 기술(`learn`, 수동 전용) ③ 특성(`props`, 특수 태그) ④ 궁극기. 대략 층마다 한 번씩 고른다.
  상태창에서 전체 선택지를 미리 볼 수 있어 빌드를 계획할 수 있다. 특수 태그 효과는 `TAG_TEXT` 주석에 구현 위치가 적혀 있다.
- **장비 3칸**: 무기 · 갑옷 · 장신구. 감정 없음. 일반(+강화) / 마법(속성 1) / 아티팩트(이름, 속성 2~3, 단점 가능).
  층 보상 3택1 + 상자·미믹·제단에서 찾은 장비. 고르면 누구에게 낄지 정하고, 바뀌는 수치를 보여 준다.
- **드롭은 적게, 대신 의미 있게**: 상자는 최소 마법 등급, 미믹·제단은 아티팩트 확정, 보상 3택1에는 파티 누군가에게
  확실히 좋은 것이 하나 이상 (`reward.ts` 의 `usefulItem`). 모두에게 손해인 템은 다시 뽑는다.
  속성은 저항 · 적중 시 효과 · 계열 위력 · 시전 속도 · 기절 면역처럼 전술을 바꾸는 쪽을 더 자주 뽑는다.
- 쓰러진 파티원은 다음 층에서 돌아온다. 전멸하면 런 종료.

## 탐험 (`sim/objects.ts`, `sim/gen.ts`)

- 층마다 곁가지 방 1~2개: 상자 + 지키는 무리 / 미믹 / 이벤트(샘 · 제단 · 포로). 자동 탐험은 들르지 않는다 — 털지 말지는 플레이어 몫.
- 오브젝트는 전투가 없을 때 아군이 그 위로 가면 작동. 이벤트는 선택지를 띄우고 그동안 멈춘다.
- 소모품 벨트(4칸, 파티 공용): 회복 물약 · 추방 두루마리 · 공포 두루마리 · 화염 폭탄 (`data/consumables.ts`).

## 스트레스 (`sim/stress.ts`, `data/moods.ts`)

- 다키스트 던전 단순화. 큰 피해 · 체력 위험 · 동료 쓰러짐 · 곁방 · 미믹 · 매복으로 오르고, 전투 종료 · 처치 · 상자 · 샘 · 진정 향초 · 층 사이 휴식으로 내린다.
- 100 이 되면 붕괴 75% (겁에 질림 · 무모함 · 이기적 · 망설임 — 자동전투 행동이 망가지고 명령을 가끔 거부) / 각성 25% (굳건함 · 집중).
- 의지력이 높을수록, `stress_ward` 태그(하플링 · 맑은 정신)가 있을수록 덜 받는다.

## 조작 부담 줄이기

- 플레이어의 역할 (2번 방향): AI 는 처음 2개 기술과 평타·치유·카이팅만 한다.
  특성으로 배운 3·4번째 기술은 **수동 전용**(`manualOnly`, 강하고 재사용 대기가 김) — 파티 카드에 준비되면 빛나는 버튼으로 쓴다.
  예고 공격 피하기, 시전 끊기도 AI 가 하지 않는다 (파티 AI 는 시전 중인 적을 일부러 노리지 않음).
- 사제의 정화는 자동 전용(`autoAbilities`)
- 파티 이동은 우르르 용병단식 조이스틱: 터치는 빈 곳을 한 손가락으로 끌기, PC 는 방향키 (`World.steer`). 화면 이동은 두 손가락
- 기본은 자동전투 + 자동 탐험(전투가 없으면 다음 방 → 계단). 위기 순간(적 범위 공격 예고, 아군 체력 35% 미만)에 감속/일시정지
- 난이도 목표: **손을 놓으면 대체로 지고, 개입하면 대체로 이긴다.** 4~5층에 오우거(내려찍기). 난이도 3단계(`data/difficulty.ts`, 시작 화면에서 선택).
  `npm run sim -- 시드 판수` (자동만) 와 `npm run sim -- 시드 판수 skilled` (수동 기술 · 예고 공격 피하기 · 붙은 적 시전 끊기 ·
  소모품 · 곁가지 방 털기를 흉내) 를 비교한다. `DIFF=easy|normal|hard`, `ASSIST=learn,dodge,interrupt,items,explore`.
  보통 난이도 기준: 자동전투만 약 33%, 개입 흉내 약 81%. 전투 템포: 적 체력 ×2 · 피해 ×0.85 (`world.ts` ENEMY_HP · ENEMY_DMG), 파티 재사용 대기 ×0.65 (`stats.ts` PARTY_COOLDOWN). `COMP=dwarf:warrior,orc:berserker,...` 로 파티 구성을 바꿔 돌릴 수 있다.

## 화면

- 캐릭터 카드의 ⓘ: 상태창 (능력치 · 스트레스 · 종족 특성 · 특성 선택지 · 기술 · 장비)
- 하단 4열: 캐릭터마다 위에 스킬 버튼(누르면 그 캐릭터로 사용, 길게 누르기/우클릭 = 자동 사용 켜기·끄기), 아래에 상태창
- 수동 전용 기술은 같은 줄에 금색 테두리로, 준비되면 빛난다
- 아군 한 명을 고르면 오른쪽 위에 능력치·장비·특성 (작은 화면에선 생략)
