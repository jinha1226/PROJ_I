# 차원 균열 · 그림

## 방향 (2026-10-20 확정)

그림은 **0x72 「16x16 DungeonTileset II」**(CC0, https://0x72.itch.io/dungeontileset-ii)를 바탕으로 한다. 필요한 것은 픽셀 단위로 고쳐서(색 바꾸기·뒤집기·겹치기) 만든다.

**왜 이 팩인가**
- 게임 화면에서 칸 하나는 28~54px이다. 16px 픽셀 그림은 이 크기로 2~3배 확대해도 선명하다.
- 앞서 생성한 회화풍(Codex)은 이 크기에서 뭉개졌고, 단순화해도 DCSS 타일과 섞이면 어색했다.
- 캐릭터가 원래 2등신 SD여서 작아도 누구인지 읽히고, 걷기·대기·맞기 애니메이션이 들어 있다.
- CC0라서 고쳐 쓰고 공개 저장소에 올려도 된다.
- 약점도 있다. 던전 전용 팩이라 풀밭·물·현대·SF·바다는 없다. 그런 세계는 같은 팔레트로 픽셀을 직접 만들어 채운다(아래).

## 파이프라인

- 원본 팩: `assets/src/0x72/` (frames, 전체 시트, README, LICENSE)
- 보충 팩: `assets/src/superdark/` — Superdark의 16x16 Enchanted Forest Characters, 16x16 Free NPC Pack (0x72 그림체 보충 팩, 무료·수정·상업 사용 가능, 출처 불필요). 파일 이름을 `sd_<이름>_<idle|run>_anim_f<n>`으로 맞췄다. 32×32 캔버스라 변환 때 모든 프레임을 합친 테두리로 여백을 자른다.
- 같은 작가의 「16x16 Samurai Fantasy Characters」는 유료($2.99, CC0, 원본 재업로드 금지). 무협에 쓰려면 구매가 필요하다.
- 변환 규칙: `tools/art72.js`의 `SPEC` — 게임 키 → 원본 프레임 + 편집
  - `src`: 원본 이름. `_anim`이면 f0~f3 프레임이 애니메이션이 된다. 목록이면 지형 변형
  - `run` 걷기, `hit` 맞을 때 한 장 → `<키>_run`, `<키>_hit`
  - `ed`: 편집 목록. `hue`(색상 회전, `only`로 특정 색만), `map`(색 → 색), `tint`(덧칠), `fill`(투명한 곳 채우기), `flip`, `over`(다른 프레임 얹기)
- 만들기: `node tools/art72.js` → `assets/art/<키>[_n].png` + `js/artset.js`
- 엔진: 같은 키의 DCSS 타일보다 우선한다. 원본 1px = 칸/16로 키우고, 세로로 긴 캐릭터는 발을 칸 아래쪽에 맞춘다. 걸을 때 `_run`, 맞을 때 `_hit`(`js/render.js`)
- PNG 읽기·쓰기는 `tools/png.js` (외부 라이브러리 없음)
