# 심연 약탈자 · Abyss Raiders (PROJ_I)

판타지 익스트랙션 액션 게임. 던전 한 층에 들어가 적을 베거나 피하며 상자와 시체를 털고, 랜턴 기름이 떨어지기 전에 탈출구로 빠져나와야 한다. 죽으면 가지고 들어간 모든 것을 잃는다. 이후 인크레멘탈(자동화·업그레이드) 게임으로 감쌀 예정이다.

## 실행

```bash
npm ci
npm run assets -- --dungeon   # KayKit CC0 에셋 다운로드 (public/assets/kaykit)
npm run dev                   # http://localhost:5173
```

`npm test` 단위 테스트 · `npm run sim` 자동 레이드 밸런스 시뮬레이션 · `npm run build` 프로덕션 빌드

## 조작

`WASD` 이동 · `좌클릭` 공격(3단 콤보) · `Space`/`우클릭` 회피(무적 시간) · `Shift` 달리기 · `E` 상자 열기 · `Tab` 가방 · `M` 지도 · `1`/`2` 벨트 아이템 · `G`/`H`/`B` 자동 귀환/탐험/전투 켜기·끄기 · `Esc` 일시정지
가방: 드래그로 이동, 드래그 중 `R` 회전, 클릭으로 메뉴, 패널 밖으로 끌어 버리기. 모바일은 가상 조이스틱과 버튼.

## 구성

- **레이드**: 절차 생성 던전(방 13개), 탈출구 3곳, 랜턴 기름 게이지(소진 시 강제 귀환, 가방 50% 손실)
- **적**: 해골 전사(휴면 기상), 해골 마법사(마법탄), 경쟁 약탈자 NPC(석궁·단검, 상자를 먼저 털어감)
- **아이템**: 재화·고물·재료·장비·유물·소모품, 타르코프식 칸 가방(회전·스택), 희귀도별 수색 시간
- **야영지**: 건물 7곳이 곧 업그레이드 트리 — 대장간·연금술사의 탑·시장·여관·병영·지휘탑. 비용은 골드 + 레이드 재료, 제작 포함
- **자동화**(지휘탑): 자동 귀환 → 자동 탐험 → 자동 전투, 각각 3레벨

## 코드 구조

- `src/sim` — 렌더러와 무관한 게임 로직(레이드, 플레이어, 적 AI, 자동화 봇). 입력은 `SimInput` 하나뿐이라 사람과 봇이 같은 경로로 조작한다.
- `src/items`, `src/meta` — 인벤토리·루팅·상점·업그레이드·제작(순수 함수)
- `src/world` — 맵 생성, 충돌, 시야, 플로우 필드
- `src/render` — three.js 렌더링(인스턴싱 던전, 캐릭터, 이펙트 풀, 야영지)
- `src/ui`, `src/game` — DOM UI와 화면 흐름
- `old/` — 이전 자동 원정 프로토타입 백업(빌드·테스트 제외)

## 차원 균열 · Infinite Rift (`inc/`)

다섯 세계(판타지·무협·수선·SF·크툴루)가 2D 타일 맵 위에서 자동으로 굴러가는 인크레멘탈 프로토타입. 세계마다 스킬트리, 공용 넥서스 트리, 차원 붕괴(환생).
빌드 없는 바닐라 JS — `inc/index.html`을 바로 열면 된다. 배포 주소: `/inc/`. 설계는 `inc/DESIGN.md`, 밸런스 봇은 `node inc/test/sim.js [분]`.
