# PROJ_I — Dungeon Expedition MVP

브라우저에서 실행하는 **노드형 던전 + 자동전투 + 탐험 로그 + 영구 성장** 프로토타입입니다.

## 실행

`index.html` 파일을 브라우저에서 열면 됩니다. 별도의 패키지 설치나 빌드 과정은 없습니다.

## 포함 기능

- 10개 노드로 이루어진 던전 시각화와 자동 이동
- 전투 / 보물 / 함정 / 야영 / 보스 이벤트
- 단순 파티 전투: 공격, 피격, 회복, 전멸
- 골드 수집, 가방 제한, 체력 부족 시 자동 귀환
- 무기·방어구·가방·탐색 속도 영구 업그레이드
- 1× / 2× / 4× 진행 속도
- 탐험 로그, 마지막 탐험 결과, 최고 진행도
- localStorage 자동 저장 및 초기화

## MVP의 의도적인 제한

- 실제 3D 이동, KayKit 모델, 애니메이션은 **아직 포함하지 않습니다**.
- 파티 3명은 개별 AI가 아닌 **공유 체력·공격력**으로 단순화했습니다.
- 노드 배열은 고정되어 있으며 장비 드롭·직업 변경·분기 탐색은 없습니다.
- 브라우저가 닫힌 동안 진행되는 오프라인 보상은 없습니다.

## 다음 검증 과제

1. 전투/탐색/운반의 병목이 플레이어에게 분명히 드러나는가?
2. 강화 이후 재탐험이 실제로 더 효율적으로 느껴지는가?
3. KayKit 3D 시각화는 시뮬레이션 로직과 분리해 추가할 것.
