# PROJ_I — 3D Expedition MVP

3D 던전에서 **전사·궁수·성직자 파티가 자동 탐험하고 전투하는 장면**을 관찰하는 브라우저 프로토타입.

## 플레이

GitHub Pages: https://jinha1226.github.io/PROJ_I/

GitHub 저장소 **Settings → Pages → Build and deployment → Source → GitHub Actions** 설정 필요. Actions 테스트 성공 후 배포됩니다.

로컬 실행은 정적 HTTP 서버를 권장합니다. 예: `python -m http.server 8000` 후 브라우저에서 `http://localhost:8000` 접속.

## 현재 구현

- Three.js 기반 쿼터뷰 3D 방·복도, 파티 추적 카메라
- 분기형 10개 방과 방문 시 드러나는 미탐색 구역
- 3명 파티의 실제 이동, 근접 공격, 원거리 투사체, 회복
- 몬스터 추격/공격, 피격 이펙트, 전투 로그, 보스
- 보물 상자, 야영지, 가방 제한, 자동/수동 귀환
- 무기·방어구·가방·정찰 업그레이드 및 localStorage 저장
- 1×/2×/4× 속도, 모바일 대응 UI

## 에셋 상태

**현재는 KayKit 모델이 아닙니다.** 우선 실제 3D 이동과 전투를 검증할 수 있도록 코드로 생성한 단순 캐릭터·던전 프리미티브를 사용합니다. Three.js의 GLTFLoader를 준비했지만 실제 KayKit GLB 파일은 아직 연결하지 않았습니다. 라이선스 확인과 에셋 파일 추가 후 교체할 예정입니다.

## 알려진 한계

- 전투는 기본 공격·투사체·회복 위주이며 아직 스킬/상태이상/전술 AI가 없습니다.
- 방/복도는 고정 배치이며 지도는 탐험할 때마다 초기화됩니다.
- CI는 JavaScript 구문·구성요소를 검사하지만 **브라우저 E2E나 전투 밸런스는 검증하지 않습니다**.
- Three.js는 CDN에서 불러오므로 최초 실행에 인터넷 연결이 필요합니다.
