# 던전 개척단 — 설계 노트

림월드식 정착지 + DCSS식 던전 탐험. 브라우저에서 `index.html`을 열면 바로 실행된다 (빌드 없음, 외부 라이브러리 없음).

## 1. 조사: Dungeon Settlers (CanOpener)

- **전제**: 길드가 보낸 원정대가 황무지에 전진 기지를 세우고, 세상의 재앙을 일으키는 던전을 파괴한다.
- **정착지**: 벽·문을 세우고 침실·식당으로 욕구를 관리한다. 대장간·제련소·농장을 짓고, 원정용 **휴대식량과 야영 보급품**을 만든다. 개발사는 림월드와 비교하는 "자유도 높은 기지 건설"을 내세웠다.
- **정착민**: 6개 주요 능력치, 재능, 종족·배경·성격 특성이 있다. 후보를 "골라서" 영입한다. **영구 사망**이라 키운 대원을 잃으면 기지 전체 계획이 흔들린다.
- **던전**: 들어갈 때마다 층 구조와 환경 효과가 바뀐다. 깊을수록 희귀 자원과 강한 적(골렘, 산성 괴물)이 나온다. 피를 바치는 고목, 만드라고라 같은 선택지가 있다.
- **전투**: 위에서 내려다보는 실시간+일시정지 방식, 4인 파티. 스킬 트리는 검·둔기·활·마법이 무작위로 조합된다. 상태이상은 기절·출혈·화상·도발·취약·돌진·소환.
- **진행**: 탐험에서 얻은 자원 → 정착지 발전·연구 → 더 깊은 층.
- **평가** (Steam '매우 긍정적', 2026년 9월 앞서 해보기):
  - 좋은 점: 중독성, 위험을 건 탐험의 보람, 후보 선별과 파티 시너지 구성의 재미.
  - 나쁜 점: 콘텐츠와 연구 트리가 얕다. 난이도가 급등하고 한 방에 죽는다. 정착지 시뮬레이션이 빈약하다(정착민이 놀고, 4명 넘게 늘릴 이유가 없다). 자동화가 부족하다. 캐릭터를 과하게 다시 뽑게 된다. 조작이 불편하다.

출처: invenglobal 프리뷰, turnbasedlovers, vaporlens 리뷰 요약, playpile.

## 2. 이 프로토타입의 기둥

1. **정착지와 던전은 같은 시계를 쓴다.** 던전 1턴은 정착지 1틱이다. 원정 중에도 농사·제작·습격이 진행된다.
2. **정착지에 사람을 남길 이유가 있다** (리뷰의 "4명 넘게 늘릴 이유 없음"에 대한 답).
   - *던전 압력*은 시간이 지나면 차오르고, 100%가 되면 입구에서 괴물이 쏟아진다.
   - 원정에서 괴물을 처치하고 새 깊이에 도달하면 압력이 줄어든다. 탐험이 곧 방어다.
3. **읽을 수 있는 위험** (리뷰의 "원샷·난이도 급등"에 대한 답). 전투는 DCSS식 턴제다.
   - 적 이름을 파티 레벨 기준 위협도 색으로 표시하고, 특수 능력 설명을 붙인다.
   - 습격 직전(85%)에 경고한다.
4. **귀찮은 일은 자동화한다.** 생산은 목표 수량 방식(빌)이다. 자동 탐험·휴식·이동, 원정 시 빈 슬롯 자동 장비를 지원한다. 개척단 구성은 마음껏 다시 뽑을 수 있다.
5. **던전에서만 나는 재료가 정착지를 키운다.** 철광석·가죽·뼈·수정·정수·고대 유물이 연구와 장비가 되고, 그 장비로 더 깊이 내려간다.

## 3. 구현된 것

| 영역 | 내용 |
|---|---|
| 정착민 | 종족 5, 배경 10, 특성 13, 힘/민첩/지능, 전투 기술 8 + 작업 기술 6 (사용하면 오름), 레벨, 영구 사망, 묘지 |
| 욕구 | 배고픔·휴식·기분. 생각(식탁/바닥 식사, 침대/맨바닥 수면, 동료의 죽음, 원정 성공 등). 기분이 바닥나면 정신적 한계로 배회한다 |
| 작업 AI | 우선순위표(1~3/끔): 요리·건설·농사·채굴·벌목·제작·운반·연구. 예약, 창고에서 재료 가져오기, 수확물 직접 운반 |
| 건설 | 나무/돌 벽(사각형 테두리 드래그), 문, 침대, 식탁, 화덕, 작업대, 연구대, 대장간, 연금술대, 치료 침대, 모집 게시판, 가시 함정, 길잡이 돌 |
| 생산 | 레시피 34종, 목표 수량 유지 방식 |
| 연구 | 11종. 연구 점수 + 던전 재료가 필요하다. 고대 유물은 연구 점수 150 |
| 습격 | 정착지를 지키는 정착민의 힘에 맞춰 규모가 정해진다. 벽·문을 부수며 접근하고, 함정에 걸린다. 정착민은 자동으로 싸우거나(겁쟁이·중상자는 도망) **징집**해서 직접 배치한다 |
| 지원자 | 주기적으로 찾아온다. 모집 게시판이 있으면 3명 중 고른다. 던전에서 포로를 구출해도 합류한다 |
| 던전 | 10층(방+통로 / 동굴), 4가지 테마, 시야·기억, 문, 물·용암, 광맥 채굴, 만드라고라, 피의 고목, 보물상자, 포로. 지하 10층에 **던전의 심장**(보스, 하수인 생성) |
| 전투 | 명중/회피/방어, 무기 속도, 기습(잠든 적 1.5배), 상태(중독·감속·기절·괴력·신속·도발), 무기 특성(화염·냉기·맹독·보호) |
| 파티 | 최대 4명. 조종 대원을 Tab으로 전환하고, 나머지는 AI(치유, 원거리, 능력 사용). 자리 지킴, 수동 지휘(모든 대원 직접 조종) |
| 능력 | 무기 기술 2 이상에서 해금: 연속 베기, 기절 강타, 휩쓸기, 조준 사격, 도발(방패). 주문: 마법 화살, 화염 화살, 치유, 점멸, 감속 |
| 가방 | 용량 = 10 + 대원 힘의 합 + 배낭. 남는 공간에 전리품을 담는다. 전멸하면 모두 잃는다 |
| 기타 | 자동 저장(매일, 원정 전후), 이어하기 |

## 4. 파일

- `js/core.js`: 유틸, 시야(그림자 투사), BFS, 다익스트라, 직선
- `js/data.js`: 모든 수치·콘텐츠 정의
- `js/chars.js`: 정착민 생성, 능력치, 전투 판정 (정착지·던전 공용)
- `js/settle.js`: 정착지 시뮬레이션 (DOM 없음)
- `js/dungeon.js`: 던전 생성, 턴 스케줄러, AI (DOM 없음)
- `js/state.js`: 상태 생성과 저장
- `js/render.js`, `js/ui.js`, `js/main.js`: 캔버스, 패널, 입력, 루프
- `test/sim.js`: 헤드리스 연기 테스트 (`node test/sim.js 6 4`)
- `test/balance.js`: 봇이 정착지를 운영하며 원정을 반복하는 밸런스 시뮬레이션 (`node test/balance.js 3 60 -v`)

## 5. 결정 기록

- **실시간+일시정지 대신 DCSS식 턴제**를 택했다. 요청이 "DCSS식 던전크롤"이었고, 원작 리뷰의 "한 방에 죽는다"는 불만을 줄이는 데도 턴제가 낫다.
- 던전 1턴 = 정착지 1틱으로 시간을 맞췄다. 원정 중에 정착지가 따로 빨리 감기되지 않고 함께 흐르므로, 원정 중 습격 알림이 의미를 가진다.
- 수확한 작물이 운반 우선순위에 밀려 바닥에 쌓이다 굶어 죽는 일이 생겼다. 그래서 농부가 수확물을 직접 창고로 나르고, 배고프면 바닥 더미에서도 먹게 했다.
- 습격 규모를 날짜와 깊이에 맞췄더니, 원정대가 집에 있을 때 트롤 떼가 오고 집 지키는 사람이 몰살당했다. 그래서 **지금 정착지에 있는 정착민의 힘**(레벨·무기·갑옷)에 맞추고, 가장 강한 개체에도 상한을 뒀다.
- 정착지에서는 무기가 없는 정착민도 농기구(피해 5)로 싸운다.

## 6. 열린 질문

- 매 원정을 1층부터 다시 내려가는 반복이 지루한가? 지금은 길잡이 돌(4·7층 시작)로만 해결한다. "계단 표식" 같은 중간 지름길도 고려해 볼 만하다.
- 실시간 정착지 ↔ 턴제 던전의 체감 속도 차이. 원정 중 정착지를 미니맵이나 알림으로 더 보여줄지.
- 원작의 "식량 부패"를 넣을지. 넣으면 휴대식량의 가치가 커진다.
- 그래픽: 지금은 브로그식 글리프다. 무료 타일셋(예: DCSS 타일, CC0)으로 갈아 끼울 수 있게 렌더러가 분리되어 있다.
- 모바일: 우클릭(징집 이동)과 키보드 의존을 터치 UI로 바꿔야 한다.
