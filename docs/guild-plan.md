# 길드 원정 루프 구현 계획서

> 상태: **계획만 확정, 구현 전** (2026-10-14)
> 관련 시제품: `?lab` 비주얼 실험실 · `?mix` 용병 부품 조합 · `?raidtest` 5인 보스 레이드

## 0. 확정된 결정

| 항목 | 결정 |
|---|---|
| 게임 구조 | **자동 원정(방치 수익)** + **최전선 직접 플레이(익스트랙션 + 보스 레이드)** 의 이원 구조 |
| 최전선 사망 | **캐릭터 영구 사망**(장비 포함 전부 잃음) |
| 자동 원정 결과 | 실제 시뮬레이션 없이 **통계 모델**로 먼저 구현 (나중에 `npm run sim`으로 보정) |
| 용병단 정원 | 시작 4명, **병영 업그레이드 노드로 증가** |
| 파티 조작 | 최전선은 한 명 직접 조작 + AI 동료, `Z` 모여 / `C` 흩어져 같은 간단한 지휘 |
| 캐릭터 에셋 | KayKit 모험가 5종 부품 조합(`src/render/mercLook.ts`) + 옷 색 |

## 1. 한 판의 흐름

| 단계 | 플레이어 행동 | 시간 |
|---|---|---|
| ① 귀환 확인 | 자동 원정대 결과(전리품·경험치·부상·사건) 확인 | 수십 초 |
| ② 가방 정리 | 원정 전리품 상자를 칸 가방으로 창고에 정리, 고물 일괄 판매 | 1~2분 |
| ③ 길드 관리 | 장비 분배, 레벨업 특성 선택, 부상자 교체, 시장에서 영입 | 1~3분 |
| ④ 다음 원정 | 정복 층 선택 → 파티 배정 → 철수 기준 설정 → 출발(방치) | 수십 초 |
| ⑤ 최전선(선택) | 미정복 층에 파티를 데리고 직접 진입 → 파밍 → 층 보스 레이드 → 정복 | 5~10분 |
| ⑥ 은신처 강화 | 건물·기술 트리 강화 | 1분 |

최전선을 정복할수록 자동 원정 범위가 넓어지는 순환이 핵심이다.

## 2. 용병

### 2-1. 데이터
```
Merc {
  id, name, cls: 'tank' | 'melee' | 'ranged' | 'healer',
  level (1~20), xp,
  traits: TraitId[],          // 영입 시 1~2개 + 레벨 5·10·15에 1개 선택
  look: MercLook,             // 부품 조합 외형 (저장)
  equipment: {weapon, armor, trinket, belt0, belt1},
  tactics: 0..1,              // 전술 숙련도 = 보스 레이드의 aiSkill
  status: 'ready' | 'expedition' | 'injured' | 'dead',
  injuredUntil: number | null,
}
```

### 2-2. 직업
| 직업 | 모델 | 역할 | 기본 스킬(레이드 시제품과 동일) |
|---|---|---|---|
| 기사 | Knight | 탱커 | 도발, 방패 막기 |
| 야만전사 | Barbarian | 근접 딜러 | 강타, 집중 |
| 사냥꾼 | Rogue_Hooded | 원거리 딜러 | 다중 사격, 집중 |
| 마법사 | Mage | 힐러 | 치유, 치유의 비 |

### 2-3. 특성 초안
- **긍정**: 철벽(받는 피해 -15%), 날쌘 손(루팅 +30%), 강골(체력 +20%), 보물 사냥꾼(희귀 드랍↑), 노련함(경험치 +25%), 침착함(장판 반응↑), 응급처치(원정 중 회복)
- **부정**: 겁쟁이(체력 30%에 먼저 귀환), 욕심쟁이(루팅↑, 귀환 늦음), 허약(부상 회복 느림), 굼뜸(이동 -10%), 덜렁이(장판 반응↓)
- 구현은 기존 보정치 구조(`RaidModifiers`와 같은 방식)로 캐릭터별 보정값을 합산한다.

### 2-4. 영입 · 유지
- 시장(또는 병영)에 영입 후보 3~4명. 일정 시간마다 갱신되고, 골드를 내면 즉시 갱신한다.
- 후보마다 직업·레벨·특성·몸값이 다르다. **레벨 높고 좋은 특성일수록 비싸다.**
- 원정마다 **급여**(레벨 비례)를 낸다. 골드를 쓸 곳이 생기고, 로스터를 정리할 이유가 된다.
- 해고하면 장비는 창고로 돌아온다.

## 3. 층 구조
- 1층부터 깊어지며 적 강화, 보상 등급, 층 전용 재료가 바뀐다.
- 각 층의 끝에 **층 보스 레이드**가 있다(1층 = 해골 군주, `src/raidboss/`).
- **최전선** = 아직 정복하지 못한 가장 깊은 층. 보스를 잡고 탈출하면 정복 → 자동 원정 대상이 된다.

## 4. 자동 원정 (통계 모델)

### 4-1. 적정 전투력과 성공 확률
원정을 보내기 전에 **"권장 전투력"과 "예상 결과"를 보여준다.** 운에만 맡기지 않고, 플레이어가 파티를 키워서 확률을 올리는 판단을 하게 만드는 것이 목적이다.

```
파티 전투력 P = Σ(용병 전투력) × 직업 조합 보정
  용병 전투력 = 레벨 기반 기본값 + 장비 점수 + 특성 보정
  직업 조합 보정: 탱커·힐러가 있으면 +, 같은 직업만 있으면 -
층 권장 전투력 R(floor) = 층마다 정해진 값 (층이 깊을수록 가파르게 증가)
비율 x = P / R
```

| x (P / R) | 결과 분포 예시 | 화면 표시 |
|---|---|---|
| 0.6 미만 | 대부분 실패 | 위험 (빨강) |
| 0.6 ~ 0.9 | 성공 40% · 조기 철수 35% · 실패 25% | 어려움 (주황) |
| 0.9 ~ 1.2 | 성공 75% · 조기 철수 20% · 실패 5% | 적정 (초록) |
| 1.2 이상 | 대성공 비율 증가 | 여유 (파랑) |

- 결과는 성공/실패 두 가지가 아니라 **4단계로 나눈다**: 대성공(보너스 전리품) / 성공 / 조기 철수(전리품 절반) / 실패(전리품 없음, 부상).
- **자동 원정에서는 죽지 않는다.** 실패는 부상(회복 시간)으로 처리한다. 영구 사망은 최전선에서만 일어난다.
- 전술 숙련도가 높을수록 실패·부상 확률이 줄어든다(보스 레이드 시뮬레이션의 aiSkill 결과와 같은 경향).

### 4-2. 진행
- 파티 1~4명, 실제 시간 2~10분. 오프라인 진행은 최대 8시간분.
- 철수 기준(파티별): 가방 80% / 체력 50% / 끝까지. 기준이 공격적일수록 전리품↑ 실패 확률↑.
- 전리품은 기존 상자 테이블(`rollContainer`)로 "방문한 상자 수" 만큼 굴린다. 층이 깊을수록 좋은 테이블을 쓴다.
- 귀환 결과: 전리품 상자(칸 가방 정리), 경험치, 부상, 사건 메시지.

### 4-3. 보정 방법
`tests/balance.sim.test.ts`(npm run sim)처럼 실제 파티 시뮬레이션을 돌려 층별 생존율·수익을 측정하고, 통계 모델의 분포를 그 값에 맞춘다.

## 5. 최전선 (직접 플레이)
- 파티 최대 4명. 한 명은 직접 조작, 나머지는 AI 동료(보스 레이드 시제품의 역할별 AI를 던전으로 이식).
- 흐름: 던전 파밍(현재 레이드) → 층 보스 방 → 보스 레이드 → 탈출구 귀환.
- 랜턴 기름, 탈출, 칸 가방 규칙은 그대로 유지한다.
- 사망 시 해당 용병은 **영구 사망**하고 장비도 잃는다. 출발 전에 경고를 표시한다.
- 필요 작업: 적 AI가 "가장 위협적인 아군"을 노리는 **어그로 시스템**(보스 레이드의 threat 로직 재사용).

## 7. 구현 단계

| 단계 | 내용 | 완료 기준 |
|---|---|---|
| **M1 용병 기반** | Merc 데이터·저장, 병영 화면(명단·장비창), 시장 영입·해고, 급여, 정원 노드, 야영지에 용병 표시 | 영입하고 장비를 입힐 수 있음 |
| **M2 자동 원정** | 원정 게시판(층·파티·철수 기준), 권장 전투력·예상 결과 표시, 타이머·오프라인 진행, 통계 결과, 전리품 상자 정리, 경험치·부상 | 방치 수익 루프 완성 |
| **M3 최전선 파티** | 던전에 AI 동료 합류, 어그로 시스템, 층 보스 방 → 보스 레이드 연결, 정복 처리, 영구 사망 | 직접 플레이 루프 완성 |
| **M4 성장** | 레벨업 특성 선택, 2층 보스(새 패턴), 층별 재료, 기술 트리 재편 | 2개 층 분량 진행 |
| **M5 밸런스** | 시뮬레이션으로 원정 수익·생존율·비용 곡선 조정 | 첫 30분~2시간이 매끄러움 |

M1 → M2를 먼저 하는 이유: 원정만으로도 "길드를 키우는 재미"를 확인할 수 있고, 가장 큰 작업인 M3의 방향을 그 경험을 보고 정할 수 있다.

## 8. 기존 코드 활용
- **그대로**: 아이템·칸 가방·상자 테이블, 던전 생성·방 테마, 전투·이펙트, 3D 야영지·기술 트리, 보스 레이드 시뮬레이션(`src/raidboss`), 부품 조합(`src/render/mercLook.ts`), 밸런스 시뮬레이터
- **변경**: 자동 탐험·전투·귀환 봇(`src/sim/auto`)은 최전선 동료 AI와 원정 보정용 시뮬레이션으로 이전. 지휘탑 자동화 노드는 원정대 효율 노드로 교체
- **보류**: 픽셀 모드·쥬피터헬풍 조명(실험실에서 계속 비교)
